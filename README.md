A static lead-capture microsite hosted on GitHub Pages.

## Live structure

- `index.html` — landing page and registration form
- `thankyou.html` — brochure access page
- `style.css` — responsive design
- `script.js` — validation and Formspree submission
- `images/hero.jpg` — hero photograph
- `files/brochure.pdf` — confidential project briefing
